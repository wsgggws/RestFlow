# Focus noise

Twelve locally synthesized, deterministic ambient noise loops; no music or external recordings.
Regenerate using `python3 scripts/generate-noise.py` (Python standard library only).
Each is 16 seconds, mono PCM 16-bit / 22.05 kHz, with an overlapping seam and 0.45 peak headroom.
Environmental names describe synthesized textures, not field recordings.
macOS alert sounds are loaded from the system and are not redistributed.
