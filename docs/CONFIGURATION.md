# 配置文件 / Configuration

设置保存在 `~/.config/restflow/config.json`。选择 JSON 是因为 Swift 原生支持、文案数组与 Unicode 无需自定义解析器。采用标准 UTF-8 JSON，字符串中的引号、反斜杠、换行分别写为 `\"`、`\\`、`\n`；直接输入中文和表情即可。JSON 不支持注释或末尾多余逗号。

首次运行 0.2.0 或后续版本时，若文件不存在，会迁移 0.1.0 的 UserDefaults 设置（含自定义文案和原素材引用）；已有配置文件始终优先。缺省字段使用默认值。错误字段名、错误类型、无效范围和未知语言都会被拒绝，界面显示错误。GUI 的修改自动原子保存，文件的外部修改约 1 秒后重载。修改时长不改变当前计时截止点，点击重新开始可立即应用新计划。

完整默认示例在 `Examples/config.json`。可先用设置页的“编辑配置”“在访达中显示”“重新加载”。错误配置不会被 GUI 覆盖；修复后自动恢复应用。若启动时文件已损坏，应用使用默认计划并暂停，不覆盖错误文件；运行中的错误则保留上次有效状态。

## 字段

| 字段 | 默认值 | 可选范围 / 意义 |
|---|---|---|
| `idleDetectionEnabled` | `true` | 闲置 60 秒暂停，满 300 秒回来重新专注；可关闭以阅读／看视频，锁屏仍暂停 |
| `deferEnabled` | `true` | 每段运行中的专注允许延后休息 180 秒一次 |
| `contentStyle` | `"personal"` | 旧字段，仅迁移读取；界面不再提供风格 |
| `favoriteMessageIDs` / `favoriteVisualIDs` | `[]` | 旧收藏字段，迁移后清空，不影响随机 |
| `excludedVisualIDs` | `[]` | 已删除的内置场景 ID；从选项与随机池排除，恢复内置动画时清空 |
| `schemaVersion` | `1` | 当前只支持 `1` |
| `language` | `"zh-Hans"` | `"zh-Hans"` 或 `"en"`，立即切换界面及内置文案 |
| `checkForUpdatesAutomatically` | `true` | 启动／打开菜单时自动检查 GitHub 最新 Release，同一进程两次自动检查至少间隔 24 小时；关闭后仍可手动检查 |
| `breakTransparency` | `0` | `0...1`，0 完全遮住桌面，1 透出桌面；整个背景与动画同步变淡，文字、计时与 Esc 保持可见 |
| `launchAtLogin` | `false` | 菜单中的“开机启动”；macOS 仍可要求用户批准 |
| `pauseShortcut` | `null` | 暂停／继续的全局快捷键，见下文 |
| `restartShortcut` | `null` | 重新开始的全局快捷键 |
| `restNowShortcut` | `null` | 现在休息的全局快捷键 |
| `showMenuBarTime` | `true` | 菜单中的“菜单栏显示时间”；关闭后叶子图标与菜单保留 |
| `operatingSchedule` | 工作日、上午及下午 | 见下方运行时段，旧配置缺省时使用默认时段 |
| `workMinutes` | `25` | `1...240`，分钟 |
| `shortBreakSeconds` | `30` | `5...1800`，秒 |
| `longBreakMinutes` | `5` | `1...120`，分钟 |
| `cycles` | `2` | `1...20`，多少段工作后安排长休息 |
| `prealertEnabled` | `true` | 开启工作结束前预告 |
| `warningSeconds` | `15` | `3...120`，提前秒数；若比工作时长长，在阶段开始后预告 |
| `soundEnabled` | `true` | 预告／开始／结束是否播放提示音 |
| `soundName` | `"Glass"` | `Glass`、`Tink`、`Ping`、`Purr`、`Pop`、`Blow` 等系统声音；`"__none__"` 静音，`"__random__"` 从这 6 个内置声音随机选择 |
| `soundPath` | `null` | 自定义本地声音文件，优先于 `soundName`；设置为 `null` 恢复系统声音 |
| `volume` | `0.5` | `0...1`，应用提示音音量，仍受系统音量影响 |
| `mediaPath` | `null` | 本地 PNG/JPEG/GIF/Lottie JSON；`null` 恢复默认视觉 |
| `visualID` | `"rings"` | 内置视觉 ID、`"__random__"` 或 `"__none__"`；`mediaPath` 有值时优先使用自定义素材 |
| `messages` | 12 条内置文案 | 共用文案库，0...100 条，ID 不重复；文本长度 1...2000 字符 |
| `shortMessageID` | `"eyes"` | 短休息文案 ID，或 `__random__`（随机）、`__none__`（无） |
| `longMessageID` | `"stretch"` | 长休息文案 ID，可与短休息相同；支持 `__random__`、`__none__` |

`messages` 项使用 `id`、`text`，可选 `englishText`。`text` 为原文；仅当明确设置了 `englishText` 时，英文界面显示该翻译。用户在 GUI 添加的文案不自动翻译，语言切换不改变原文。

```json
{
  "id": "my-reminder",
  "text": "喝水 💧 — \"慢一点\"\n伸展肩膀 ↗ ❤️"
}
```

用户文案按纯文本显示，不解析 Markdown；特殊符号、表情和换行可保留。新增时会将 Unicode 等价形式、大小写及多余空白视为同一文案，并与原文和英文译文比较；重复时提示选择已有文案。旧配置中的重复条目保留原文及 ID，但当前语言的下拉选项和随机池仅包含每种显示文案一次，并保留当前选中的 ID。新增文案后，在短／长休息的下拉框中选择；选中具体文案后可点击旁边的删除按钮，引用它的短／长休息选项自动变为“无”；当前语言相同的旧重复文案会一起移除。要批量编辑，可直接修改 `messages`，同时确保两个选中 ID 仍然存在（或为 `__random__`、`__none__`）。保留 ID `__random__`、`__none__` 不能用于文案条目本身。

## 无内容与静默休息（0.7.0）

当前休息类型的文案为 `__none__`，且 `visualID` 为 `__none__`、`mediaPath` 为 `null` 时，不创建全屏窗口、不显示倒计时、也不拦截键盘；计时、暂停／继续、周期和声音照常工作，菜单首行仍显示“专注／休息：剩余时间”。短／长休息分别判断，另一个阶段选择随机不会影响本阶段。

| 当前文案 | 视觉 | 本次休息 |
|---|---|---|
| 无 | 无 | 无全屏，按配置播放声音 |
| 随机／指定文案 | 无 | 全屏文案及倒计时 |
| 无 | 随机／指定素材 | 全屏视觉及倒计时，不补替代文案 |
| 随机／指定文案 | 随机／指定素材 | 全屏文案、视觉及倒计时 |

`soundEnabled: false`、`volume: 0` 或声音选择 `__none__`（且没有 `soundPath`）均不播放声音。没有全屏内容且没有声音的阶段完全安静运行，也跳过该阶段之前的预告通知。有内容或声音时，预告仍遵守 `prealertEnabled`。GUI 选择素材／声音“无”时清空对应自定义路径；文件配置保留“自定义路径优先”的规则。静默设置同样适用于“现在休息”和设置预览。随机声音在每次实际播放时独立抽取，音量／启用规则不变；`soundPath` 存在时仍优先于随机选择。

菜单栏休息时间前使用 ☕︎，暂停时优先使用 ⏸，中英文一致。菜单首行每秒更新，关闭菜单栏时间显示不影响菜单内时间；暂停时附加暂停标记。菜单栏不再使用带倒计时的悬浮 tooltip。

## 相对路径

所有相对路径相对于 **`~/.config/restflow/`**，与启动应用时的工作目录无关。也支持 `/` 开头的绝对路径和 `~/` 开头的用户目录路径；不支持远程 URL 或环境变量插值。

```json
{
  "mediaPath": "media/stretch.gif",
  "soundPath": "sounds/soft bell.wav"
}
```

上例对应 `~/.config/restflow/media/stretch.gif` 和 `~/.config/restflow/sounds/soft bell.wav`。路径可包含空格、中文与表情。直接配置是引用，不会复制或删除这些文件；GUI 导入则在配置目录下生成独立副本。Lottie 外部图片路径相对于 **该 Lottie JSON 所在目录**。

无效素材／声音会显示错误；无效素材显示默认视觉，无效声音保持静音。单个媒体／音频最大 20 MB；Lottie 外部图片最多 100 张、总大小最大 100 MB，只支持动画目录内部的相对图片引用。

## 调试预览与快捷键

菜单栏的“现在休息”使用 `BreakWindowController.restNow()`，替代当前专注并推进一次循环；每 N 次进入长休息，包含自然完成专注和手动现在休息。例如周期 2 时，先短休息，再次“现在休息”将进入长休息。设置页预览及 CLI 仍使用 `preview()`，固定短休息且不推进轮数、不写入统计。两种入口在已有休息时都不重置倒计时。冷启动预览：

```sh
open dist/RestFlow.app --args --preview --paused
```

参数只在新进程启动时读取。应用已运行时请用设置页预览。`--settings` 打开设置，`--paused` 以暂停状态启动；预览立即开始独立的短休息倒计时，并冻结真实计时。预览无顶部标题，倒计时结束、按 Esc 或点击底部 Esc 后恢复原计时的剩余时间、手动暂停及轮数；预览不触发阶段声音，且在非运行时段可用。已在休息时再次操作不会重置倒计时。

休息窗口显示期间阻止普通按键及 ⌘Tab，临时注册全局 Esc，因此窗口失焦后也可退出；关闭后移除按键监听、释放全局 Esc 并恢复系统界面状态。应用自定义的三个快捷键在休息期间暂停。无需辅助功能权限；系统锁屏及紧急退出仍可使用，不能拦截所有系统级按键。若 Esc 已被其他程序占用，设置中显示错误，仍可在休息窗口内按 Esc 或点击退出。

## 通知与错误恢复

通知的授权状态由 macOS 管理，不能通过配置文件授予；在“休息”中主动点击授权。除系统权限外，上表覆盖全部可持久化的应用设置。当前计时阶段、剩余时间、临时暂停和预览属于运行状态，不写入配置。

修复 JSON 时可使用 `python3 -m json.tool ~/.config/restflow/config.json` 检查语法。文件最大 1 MB。遇到同时编辑冲突，GUI 保留原设置，提示重新加载；先修好／重载文件，再修改 GUI，以免覆盖尚未应用的外部编辑。

## 内置文案与视觉（0.3.0）

默认计划为工作 25 分钟、短休息 30 秒、长休息 5 分钟、每 2 段工作后长休息。新配置包含 12 条文案，包含休息提醒及《道德经》《论语》《礼记》摘句，英文为释义。已有文件保持用户的计划与文案库；需要完整新默认值可参考 `Examples/config.json` 合并。

`shortMessageID`、`longMessageID` 与 `visualID` 均可设为 `"__random__"`。文案从当前共用库抽取，视觉从以下 12 款中抽取。每次休息／预览开始时选择一次，所有屏幕一致；暂停、倒计时刷新、切换语言不重新抽取。更换文案／视觉选择后立即更新。若有多个不同候选，不会连续重复上次显示的文案或场景；单个候选允许重复。随机只从未删除的内容抽取，空库等同于“无”。

| visualID | 内置场景 |
|---|---|
| `rings` | 呼吸圆环 |
| `orbit` | 环绕星点 |
| `waves` | 轻柔海浪 |
| `rain` | 听雨时分 |
| `sunrise` | 日出微光 |
| `mountains` | 远山如黛 |
| `forest` | 林间片刻 |
| `lotus` | 莲瓣舒展 |
| `stars` | 静谧星空 |
| `clouds` | 云卷云舒 |
| `bamboo` | 竹影清风 |
| `fireflies` | 萤火微光 |

内置素材是应用绘制的矢量插画／动画，无需额外素材文件。系统“减少动态效果”开启时固定动画。设置中导入素材会切换至自定义；选择内置素材会清空 `mediaPath` 并清理此前 GUI 导入的托管媒体副本；直接配置的外部文件不删除。如需保留原素材用于再次导入，请保留源文件。

自动化界面调试可冷启动附加 `--ui-test --settings --paused`，仅本次运行显示 Dock 图标以供系统自动化识别；正常启动保持菜单栏模式。

## 版本、透明度与迁移（0.6.0）

版本与更新入口位于设置 → 通用。点击“可升级至 vX.Y.Z”打开本仓库 Release 下载页；应用不自动下载或替换自身。检查使用公开 GitHub API，限流时回退同仓库官方 latest 重定向。

`breakTransparency` 控制整个背景与矢量／图片／GIF／Lottie 的透明度，默认 0（完全遮挡），越高越能看清桌面与其他窗口。文字、倒计时和 Esc 不变透明，使用柔和灰绿配色；透明度越高，文字区域的局部衬底越明显，以保持桌面内容较亮时的可读性。旧 `visualGrayness`、`visualOpacity` 字段仍接受有效范围 0...1，但旧字段只影响素材，不能表达整个背景的新含义，因此迁移后使用新默认值 0；若存在明确的 `breakTransparency` 则使用该值。GUI 保存只写新字段。旧配置中的内置文案，仅在 ID 与旧内置文本完全匹配时去除出处；自定义文本保持原样。

隐藏时间时图标区域采用系统 `NSStatusItem.squareLength`（本机实测 22 点），SF Symbol 为 18 点；相邻应用的公共间距由 macOS 管理。冷启动附加 `--diagnostics` 可读取实际按钮宽度。

## 全局快捷键与开机启动

通用设置提供三个录入按钮及各自的清除按钮。默认不绑定；录入时按目标组合，Esc 取消。至少包含 ⌘、⌃、⌥ 中的一个，允许附加 ⇧；Esc 保留给休息窗口。菜单操作右侧显示 macOS 原生修饰键。使用物理键码，字母显示跟随当前 ASCII 键盘布局。

```json
{
  "pauseShortcut": { "keyCode": 35, "modifiers": 6144 },
  "restartShortcut": { "keyCode": 15, "modifiers": 6144 },
  "restNowShortcut": { "keyCode": 11, "modifiers": 6144 },
  "launchAtLogin": false
}
```

上例为 ⌃⌥P、⌃⌥R、⌃⌥B。`modifiers` 使用 Carbon 位掩码之和：⌘=256、⇧=512、⌥=2048、⌃=4096。推荐通过界面录入。录入和文件重载均检查重复、系统符号快捷键、常用保留组合及系统注册占用；失败保留旧绑定及原文件。macOS 不提供其他应用所有局部快捷键的完整清单，未启动应用或动态拦截器的组合无法穷举。正常全局注册不要求辅助功能权限；某些系统保留按键可能先被系统处理，无法录入时换一个组合。

“菜单栏显示时间”与“开机启动”直接位于菜单的“设置…”之后、“退出”之前，勾号表示启用；通用设置不重复显示。开机启动使用 `SMAppService.mainApp`。启用后若系统要求批准，点击菜单中出现的入口在“系统设置 → 通用 → 登录项”允许；系统批准不写入 JSON。建议将应用放在 `/Applications` 后启用，移动或删除应用可能使登录项目失效。

## 独立自测

`--config-dir /绝对路径` 将配置、媒体导入和声音导入放入独立目录，初次创建使用默认配置。测试时不要启用真实登录项目。示例：

```sh
dist/RestFlow.app/Contents/MacOS/RestFlow --config-dir /tmp/restflow-test --ui-test --settings --paused
```

构建包的 `--check-system-integration` 检查 Carbon 注册、事件分发与冲突回滚，只读取登录项目状态，不启用或关闭登录项目。

`--check-break-integration` 使用临时配置和可控时钟，检查短休息倒计时、背景 alpha、失焦后的全局 Esc 及窗口／按键状态清理；会短暂显示休息窗口，不修改用户配置或登录项目。

## 应用名称（0.9.0）

设置左上角固定显示“坐忘录 · RestFlow”，应用的系统名称仍由系统语言选择。系统语言优先匹配中文时显示“坐忘录”，英文时显示 RestFlow；由 macOS Bundle 本地化选择，与 `language` 控制的界面语言独立。中文、英文都作为 Spotlight 搜索别名；安装或升级后需等待系统索引更新。应用文件名保持 `RestFlow.app`，bundle ID、配置目录和 Homebrew 命令不变。

构建时打包 `Resources/*.lproj/InfoPlist.strings`。可用 `--check-name-integration -AppleLanguages '(en)'` 或 `'(zh-Hans)'`、`'(zh-Hant)'` 验证名称资源和实际语言选择，不更改系统语言。

## 上午／下午运行时段（0.10.0）

设置 → 计划提供星期选择、上午开始／结束、下午开始／结束。默认：

```json
{
  "operatingSchedule": {
    "enabled": true,
    "weekdays": [2, 3, 4, 5, 6],
    "morningStartMinute": 540,
    "morningEndMinute": 720,
    "afternoonEnabled": true,
    "afternoonStartMinute": 810,
    "afternoonEndMinute": 1110
  }
}
```

星期按 Calendar 编码：周日 1、周一 2……周六 7。时间用当天零点起的分钟数，上午默认 09:00–12:00，下午 13:30–18:30；结束时刻不包含。开始早于结束，时段不能重叠，至少选一天。`afternoonEnabled: false` 只保留上午窗口；`enabled: false` 表示不限时段，整天运行及统计。使用当前系统时区及本地日历；不支持跨午夜的单个时段。

时段外保留菜单和设置，但停止提醒、声音及统计；专注剩余时间冻结，下个时段自动恢复。用户手动暂停不会自动解除。休息跨入午休或下班时立即关闭，保留实际秒数；未计满则记为不足，并在下个时段开始新专注。时段外“现在休息”不可用，预览仍可使用；重新开始可重置计划但仍等待下个时段。

旧配置没有此字段时也使用新默认时段，其他原有字段保持不变。修改时段立即生效，只影响后续计时，已记录历史不重新计算。

## 本地基础统计（0.10.0）

设置最后的“统计”页可选最近 7 天／30 天（含今天），堆叠柱状图按天展示计时和休息时长，文字显示总时长、完成／提前结束次数及折叠的每日明细。

数据保存在配置目录的 `statistics.json`，与偏好分开；`--config-dir` 同时隔离统计。只记录应用实际运行、计时未暂停且处于设定时段的秒数，按记录时的本地日期汇总。暂停、午休、其他非运行时段、睡眠、应用关闭和墙上时钟跳变均不补算。专注时长指计时器处于专注阶段，不记录键盘输入或衡量实际工作效率。

休息按真实计时秒数累计，最多计至该阶段截止点；自然计满记一次完成。Esc／点击 Esc、重新开始、正常退出或运行时段截断时，未计满的休息记一次不足。跨日休息的秒数分别归属各天，完成／不足次数归到最后实际计时的那一天。设置预览不计入统计。

数据仅在本地聚合，不上传、不记录应用名称或键盘输入。每约 15 秒及暂停／结束／退出时原子保存；强制结束或崩溃可能丢失最后一段尚未保存的数据及未结算的休息次数。损坏或外部修改冲突会在统计页提示，不覆盖原文件；修复并重启后恢复。统计从升级后的实际使用开始，不生成历史数据。


## 离开、延后与简洁设置

设置依次为“计划／休息／通用／统计”，休息页集中管理文案、视觉、声音与通知。配置文件操作位于通用的“高级”折叠区，统计每日明细默认折叠。声音选择“无”即静音，GUI 不再提供重复的启用开关；旧 `soundEnabled: false` 仍生效，重新选声音或导入声音会启用声音。

默认闲置 60 秒后暂停专注，前 60 秒仍属于正常计时；之后的观测时间单独记为 `awaySeconds`，仅包含运行时段。回来时闲置不足 300 秒继续剩余计时，满 300 秒则按最新计划开始新专注，保留长休息轮数。锁屏立即暂停，若正休息则提前结束并释放全屏输入保护。手动暂停不被离开／锁屏解除；睡眠、应用关闭及系统时钟跳变不补算离开时间。只读取系统闲置时长和锁屏事件，不读取按键内容或应用使用信息；阅读／视频可关闭 `idleDetectionEnabled`。锁屏与闲置不等同于已完成一次规定休息。

菜单和预告通知支持延后 3 分钟；延长的是当前阶段的截止时间，每段专注限一次，不修改持久化计划。暂停、离开、真实休息、预览及非运行时段不可延后；过期通知 action 不影响新阶段。`deferEnabled: false` 关闭入口。

0.12.0 移除收藏与风格入口。旧 `quiet` 迁移为短／长文案“无”，旧 `classical`／`movement` 迁移为随机；之后使用两个文案选择器，旧收藏不限制随机。旧内置“上善若水。”替换为“知止而后有定。”并保留选中引用；用户改写的条目不替换。

文案与动画选中具体内容后可删除；“无”与“随机”本身不能删除。内置文案和动画可恢复，用户文案不会被恢复操作覆盖。删除导入素材只移除托管副本或外部引用，原始文件保留；保存冲突时不删除文件。12 款内置场景均为动态，系统启用“减少动态效果”时静止。真实休息与预览均只提供 Esc 退出，不提供暂停按钮。

统计 UI 使用“计时”和“提前结束”，原来的 `focusSeconds`、`insufficientBreaks` 字段保留，旧统计缺少 `awaySeconds` 时读为 0。统计表示计时器状态，不衡量实际注意力或健康效果。
