# 验证

## 自动化

运行 `./scripts/test.sh`，当前为 26 项确定性检查：

- 计时：短／长休息周期、暂停继续、预告去重、重新开始、延迟刷新、后续阶段设置、提前结束、单段循环。
- 配置：默认示例、缺省字段、Unicode 往返、相对路径、灰度范围、自动更新开关、无效类型／键／文案、外部原子修改、冲突及损坏文件保护。
- 内容：12 款视觉 ID、随机选择在同次休息内稳定、译文即时切换、旧媒体配置兼容。
- 版本：数值比较、稳定版本与预发布区分、固定 GitHub Release URL、重定向来源校验。

`./scripts/build-app.sh` 构建 Release 应用并验证签名；`./scripts/package-release.sh` 打包本机架构并生成 SHA-256。GitHub Actions 在 main 推送与 PR 上重复自动化及构建。
