# 验证

## 自动化

`./scripts/test.sh`：60 项确定性检查，覆盖计时边界、暂停／继续、重新开始、预告去重、长休息周期、手动短休息及轮数保持、配置原子保存／冲突保护、Unicode 与路径、随机内容、版本比较、透明度迁移及快捷键校验；新增上午／下午时段边界、周末、午休、夏令时、随机声音、手动短长循环及统计持久化／冲突保护；包含文案 Unicode／空白／大小写与双语重复识别、旧配置选项去重与选中 ID 保持、随机池去重，以及短文案／长文案／视觉共 27 种“无／随机／指定”组合、声音选择及静默预告规则。

`./scripts/build-app.sh`：Release 构建、应用包和 Lottie 框架签名验证。构建后运行：

```sh
dist/RestFlow.app/Contents/MacOS/RestFlow --check-system-integration
dist/RestFlow.app/Contents/MacOS/RestFlow --check-break-integration
dist/RestFlow.app/Contents/MacOS/RestFlow --check-menu-integration
dist/RestFlow.app/Contents/MacOS/RestFlow --check-activity-integration
dist/RestFlow.app/Contents/MacOS/RestFlow --check-wellbeing-integration
```

第一项含 8 项原生检查，验证 Carbon 注册、事件分发、绑定转移、系统保留／已占用组合的拒绝及失败回滚，并读取登录项目状态。第二项含 40 项原生检查，使用临时配置、可控时钟及实际 AppKit 窗口，验证短休息倒计时、背景 alpha、失焦后的 Esc、自然结束、无内容时释放键盘及短／长阶段独立判断。第三项含 21 项菜单检查，经过真实状态刷新入口验证 tooltip 不存在、菜单倒计时更新及隐藏菜单栏时间后的状态。菜单检查还通过原生 action 验证两个开关的勾号、保存、登录批准入口及失败回滚，登录服务使用注入的测试替身。诊断不修改用户配置或登录项目，但第二项会短暂显示休息窗口。`--check-name-integration` 在 en／zh-Hans／zh-Hant 三种语言各执行 6 项检查，验证资源、系统选名、文件身份与双语搜索别名。`--check-activity-integration` 注入单调及墙上时间，17 项检查验证午休精确冻结、自动／手动暂停区别、按实际秒数统计、休息不足、长休息周期、睡眠及系统时钟修正。`--check-wellbeing-integration` 79 项检查覆盖闲置、锁屏、睡眠、手动暂停、恢复、独立预览及延后去重／过期 action。GitHub Actions 执行上述检查。
