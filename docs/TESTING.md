# 验证

## 自动化

`./scripts/test.sh`：30 项确定性检查，覆盖计时边界、暂停／继续、重新开始、预告去重、长休息周期、配置原子保存／冲突保护、Unicode 与路径、随机内容、数值版本比较，以及新增的透明度迁移、内置出处迁移、快捷键校验与系统集成失败保护。

`./scripts/build-app.sh`：Release 构建、应用包和 Lottie 框架签名验证。构建后运行：

```sh
dist/RestFlow.app/Contents/MacOS/RestFlow --check-system-integration
```

原生诊断验证 Carbon 注册、事件分发、绑定转移、系统保留／已占用组合的拒绝，以及失败后原动作仍能分发；读取键位显示和登录项目状态。诊断不修改配置或登录项目。GitHub Actions 运行上述三步。
