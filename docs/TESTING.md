# 验证

## 自动化

`./scripts/test.sh`：33 项确定性检查，覆盖计时边界、暂停／继续、重新开始、预告去重、长休息周期、手动短休息及轮数保持、配置原子保存／冲突保护、Unicode 与路径、随机内容、版本比较、透明度迁移及快捷键校验；包含短文案／长文案／视觉共 27 种“无／随机／指定”组合、声音选择及静默预告规则。

`./scripts/build-app.sh`：Release 构建、应用包和 Lottie 框架签名验证。构建后运行：

```sh
dist/RestFlow.app/Contents/MacOS/RestFlow --check-system-integration
dist/RestFlow.app/Contents/MacOS/RestFlow --check-break-integration
dist/RestFlow.app/Contents/MacOS/RestFlow --check-menu-integration
```

第一项含 8 项原生检查，验证 Carbon 注册、事件分发、绑定转移、系统保留／已占用组合的拒绝及失败回滚，并读取登录项目状态。第二项含 25 项原生检查，使用临时配置、可控时钟及实际 AppKit 窗口，验证短休息倒计时、背景 alpha、失焦后的 Esc、自然结束、无内容时释放键盘及短／长阶段独立判断。第三项含 7 项菜单检查，经过真实状态刷新入口验证 tooltip 不存在、菜单倒计时更新及隐藏菜单栏时间后的状态。诊断不修改用户配置或登录项目，但第二项会短暂显示休息窗口。GitHub Actions 执行上述检查。

## 0.7.0 本机结果

Apple Silicon / macOS 27.2：

| 场景 | 结果 |
|---|---|
| 自动化 | 33 项规则／配置、8 项系统、25 项休息、7 项菜单检查通过，构建及签名通过 |
| 浮动倒计时 | 修复前 `--check-menu-integration` 的 tooltip 断言失败；原状态按钮 tooltip 的字符串格式与用户截图一致。移除 tooltip 后，阶段、语言和时间开关变更均保持 nil，状态改由菜单及辅助功能值提供 |
| 菜单 | 原生检查验证“专注：25:00”随计时变为“专注：24:59”、休息显示“休息：00:30”、英文为“Rest: 00:30”；菜单栏时间开关独立 |
| 全无内容 | GUI 三个选择均为“无”，从暂停专注点击预览后仍停留设置，阶段变成运行中的短休息；原生检查验证自然短／长休息无窗口、不拦截键盘、轮次正常 |
| 随机文案＋无动画 | GUI 验证出现只有文案、倒计时、Esc 的全屏；没有动画，也不会因为另一阶段为“无”而隐藏本阶段 |
| 无文案＋指定动画 | GUI 验证只有动画、倒计时及 Esc，没有自动填充的替代文案 |
| 界面底角 | 全屏截图确认两侧底角留空；自然休息的辅助功能树只包含文案、倒计时、居中暂停和 Esc，提前结束正常 |
| 声音无 | GUI 显示系统提示音“无”，试听禁用，没有无效声音错误；播放入口通过同一声音启用规则，音量为 0 时仍可向上调节滑块 |
| 配置保护 | 全部界面测试使用 `.build/070-ui` 独立配置；发布安装保留原配置及真实登录项目 |

系统状态菜单的 UI 自动化入口为不可点击的屏幕外元素，未把原生菜单检查当作鼠标外观测试；真实菜单视觉仍可人工核对。

## 0.6.0 本机结果

Apple Silicon / macOS 27.2：

| 场景 | 结果 |
|---|---|
| 自动化与原生诊断 | 31 项确定性检查、8 项系统集成及 14 项休息集成检查通过；Release 构建与签名通过 |

| 背景透明度 | 设置拖动 0%／100% 并保存；背景与素材共用透明度处理，文字和 Esc 保留。原生像素检查实测 0% 时背景 alpha > 0.99、50% 时约 0.502、100% 时为 0；窗口为非 opaque、透明底色 |
| 预览与现在休息 | 从暂停专注立即进入运行中的短休息；无顶部标题，只有视觉、选中文案、变化中的倒计时与 Esc；Esc 与点击均退出；5 秒实际倒计时自然结束后回到专注 |
| 按键与失焦 | 界面自动化发送 ⌘Tab、⌘W 及普通按键后仍停留休息界面，Esc 正常退出；原生诊断显式失焦后通过临时全局 Esc 退出，验证注册和退出释放 |
| 状态清理 | 提前结束、自然结束、重新开始均关闭窗口、恢复 presentationOptions、释放全局 Esc 并恢复应用快捷键 |
| 中英文 | 设置切换即时生效；透明度、预览及倒计时界面正常显示 |
| 本机保护 | 发布前测试均使用独立 `--config-dir`；不修改真实登录项目。用户已明确要求发布后升级本机，升级保留现有配置 |

透明窗口的系统自动化截图可能把透明区域合成为白色；透明度结论以原生视图 alpha 和窗口属性验证为依据。

## 延续的 0.5.0 回归证据

快捷键录入验证过系统／重复冲突提示、保存及重启恢复，原生 Carbon 分发和注册失败回滚仍纳入诊断。独立 bundle ID 的测试副本曾验证开机启动 enabled／notRegistered 两个状态并完成注销。当前版本只读取真实登录项目状态。

状态菜单使用原生 keyEquivalent／modifierMask；当前 UI 自动化工具不能读取系统状态菜单，菜单外观保留人工回归项。

## 硬件／权限回归

真实多屏热插拔、睡眠唤醒、通知授权后的横幅、实际听音、重启后的自动启动、系统要求登录项目批准的分支、真实键盘从其他应用触发快捷键、Intel 实机仍需对应设备或操作验证。单屏与原生诊断不能替代这些场景。系统锁屏／紧急退出能力保留，不能拦截所有系统级按键。

公开预编译包为 Apple Silicon 临时签名开发版本，尚未 Developer ID 签名和 Apple 公证。首次启动遵循 macOS 允许打开流程。
